# Three-in-One Game — Unity 3D source project

This is an **original, asset-free Unity prototype** containing three small playable 3D games, a main menu, and a shared in-game pause menu. It is a **source project**, not a precompiled .exe or WebGL build. You must open it in Unity to create scenes and test/export it.

## Getting started (Unity 2022.3 LTS / Unity 6)

1. Extract this entire ZIP file into a normal folder.
2. Open **Unity Hub → Add project from disk** and choose the extracted `ThreeInOne_Unity_2026` folder (the one that contains `Assets`, `Packages`, and `ProjectSettings`).
3. Open using Unity **2022.3 LTS** (recommended) or a compatible newer Unity editor. Let Unity import and compile all scripts.
4. In the editor menu select **Tools → Three-in-One Game → Generate All Four Scenes**. The generator creates `Assets/Scenes/MainMenu.unity`, `Driving.unity`, `Flying.unity`, and `Sumo.unity` and automatically adds all four to Build Settings.
5. The **MainMenu** scene opens automatically. Press the **Play** triangle above the editor window.
6. In **Game** view, try each button. For real mouse clicks on UI you may need to focus the Game tab.

**Input note:** This sample uses `Input.GetKey` and Unity's UGUI Standalone Input Module. If controls do not work or Unity reports an `InvalidOperationException` mentioning UnityEngine.Input, go to **Edit → Project Settings → Player → Other Settings → Active Input Handling** and choose **Both** or **Input Manager (Old)**, then restart the editor when asked.

**Editor generated scenes:** The `.unity` scene files are intentionally produced by the editor script instead of being bundled, so that Unity creates correct asset references for your installed version. Do not skip step 4.

## Games and controls

| Game | Controls | Win condition |
|------|----------|---------------|
| Mad Driver | W/Up = forward, S/Down = reverse, A/D or Left/Right = steer | Cross the finish gate 190 meters down the track while preserving 1+ health |
| Fly Like a Bird | W/Up = climb, S/Down = descend, A/D or Left/Right = move sideways, Space = speed boost | Fly through at least 5 of 8 golden rings; don't fly into the ground |
| I'm a Sumo and a Ball | WASD/arrows = roll, Space while moving = dash | Push the orange CPU ball outside the circular arena before you fall out |

In any mini-game, press **Esc** (or click Pause) to show the in-game menu:

- **Resume** restores gameplay.
- **Restart** reloads the current mini-game.
- **Back to Main Menu** returns to the main menu.

The main menu's **Exit** button stops Play mode in the Unity editor and closes the application in a standalone build.

## Build an executable

After generating the four scenes, open **File → Build Settings** (Unity 2022) or **File → Build Profiles** (Unity 6). Ensure `MainMenu` is scene index 0; choose your platform, then select **Build**. Test the build before distributing.

## Project structure

```
Assets/
  Editor/ThreeInOneSceneBuilder.cs    # generate all four scenes
  Scripts/GameEntry.cs               # navigation, Esc, round end
  Scripts/GameUI.cs                  # UGUI main, HUD, pause and results
  Scripts/GameWorld.cs               # procedural shapes + key reading
  Scripts/FollowCamera.cs            # smooth camera tracking
  Scripts/DrivingGame.cs             # drive / barriers / finish
  Scripts/FlyingGame.cs              # aircraft / ring checkpoints
  Scripts/SumoGame.cs                # physics sumo / opponent AI
  Scenes/                           # generated by editor tool
Packages/manifest.json
ProjectSettings/ProjectVersion.txt
```

## Editing

- Change the main menu title or labels in `GameUI.cs` (`ShowMainMenu`).
- Change track layout and obstacle locations in `DrivingGame.cs` (`CreateRoad`).
- Change checkpoint layout and win threshold in `FlyingGame.cs`.
- Change AI strength and movement in `SumoGame.cs`.
- Replace the generated shapes with your own original models if you want.
